# 🍺 Tavern

**One bot. Every module. A whole staff of characters.**

Tavern is an all-in-one, modular Discord bot built to replace the stack of 5–10 bots most active servers juggle today: moderation, levels, economy, casino, music, tickets, giveaways and more, configured in one place with slash commands or a web dashboard.

## ✨ What Tavern does

- **Moderation**: warns, timeouts, bans, tempbans, numbered case history, automatic escalation
- **Protection**: AutoMod (native + custom filters), anti-phishing, anti-raid, anti-nuke, captcha verification
- **Economy & casino**: wallet and bank, daily rewards, shop, blackjack, roulette, crash, mines… *with fictional currency only*
- **Music**: queue, interactive player, filters, playlists, from SoundCloud, Bandcamp, web radios and direct audio
- **Community**: levels and rank cards, welcome messages, self-assignable roles, tickets with transcripts, giveaways, suggestions, starboard
- **Dashboard**: Discord login, every setting in one place, applied live without a restart
- **Languages**: English first and French at launch, with more added through community translation

Every module can be switched on or off per server, and everything can be configured without writing code.
