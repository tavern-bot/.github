# tavern-bot/.github

This repository holds the **default community health files** for every repository in the [Tavern](https://github.com/tavern-bot) organization, plus the organization's public profile.

GitHub automatically uses these files for any repository in the organization that doesn't define its own version.

## Contents

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Public organization profile shown on [github.com/tavern-bot](https://github.com/tavern-bot) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to set up, write, test and submit changes |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behavior in all Tavern community spaces |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`LICENSE.md`](LICENSE.md) | Proprietary license (all rights reserved) |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Bug report, feature request and translation forms |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Checklist shown when opening a pull request |

## Overriding a file

To use a different version in a specific repository, add a file with the same name to that repository (at its root, in `docs/` or in `.github/`). The local file always wins.

> [!NOTE]
> A license is **not** inherited from this repository. Each repository must include its own `LICENSE` file.
