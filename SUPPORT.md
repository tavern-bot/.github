# Getting help with Tavern

Stuck? Here's where to go.

| I want to… | Go to |
| --- | --- |
| Learn what a command does | Type `/help` in your server |
| Get help setting up Tavern on my server | The official Discord support server *(link coming soon)* |
| Report a bug or suggest a feature | The official Discord support server |
| Report a security vulnerability | Follow the [security policy](SECURITY.md). **Never post it publicly.** |
| Report someone's behavior in the community | Follow the [Code of Conduct](CODE_OF_CONDUCT.md#enforcement) |
| Access or delete my personal data | Use the data commands in Discord or the dashboard |

## Before asking

- Check that the module is enabled: `/module enable <module>`
- Check that Tavern has the Discord permissions the feature needs. The error message names any missing permission.
- If a command failed with an error ID, **include that ID** in your message. It lets us find the exact error in our logs.

## For organization members

Bugs, feature requests and translations are tracked in the private [`tavern`](https://github.com/tavern-bot/tavern/issues/new/choose) repository, using its issue forms.

## Please don't

- DM maintainers directly for support. Public channels help everyone who runs into the same problem later.
